01把研究问题拆成可检索概念⌄
适用场景检索前明确概念边界、同义词和排除词
我不说帮我找一些相关文献
我会说（直接复制）
你是一名熟悉【研究领域】的科研信息检索顾问。请把下面的研究问题转换为可执行的检索概念框架。

研究问题：【粘贴研究问题】
研究对象/情境：【填写】
核心变量或现象：【填写】
时间范围：【填写】
语言范围：【中文/英文/不限】

请完成：
1. 拆分为3-5个核心概念组，解释每组与研究问题的关系。
2. 为每组提供中文关键词、英文关键词、常见缩写、近义词、上位词和下位词。
3. 列出容易造成误检的歧义词及建议排除词。
4. 给出“高召回率版”和“高精确率版”两组概念组合。
5. 对无法确定的学科术语标注“需研究者确认”，不得自行定义。

输出为：概念组表格 + 排除词清单 + 检索边界说明。不要虚构论文、作者、期刊或DOI。
使用提醒先确认术语含义，再进入数据库检索；跨学科主题尤其需要检查同名异义词。

02生成数据库可直接使用的检索式⌄
适用场景针对不同数据库分别适配字段和语法
我不说给我一个搜索关键词
我会说（直接复制）
请基于以下概念框架，为【Web of Science / Scopus / PubMed / Google Scholar / CNKI，按需保留】分别生成可复制的检索式。

概念框架：【粘贴上一条输出】
目标文献类型：【实证研究/综述/方法论文/不限】
年份范围：【填写】
学科限制：【填写】

要求：
1. 正确使用 AND、OR、NOT、引号、截词符、字段标签和括号。
2. 每个数据库分别给出宽检索式、平衡检索式和精确检索式。
3. 逐段解释每个语句块的作用，并指出可能遗漏的主题表达。
4. 给出首次试搜后的迭代规则：结果过多、过少或偏题时分别如何调整。
5. 不确定数据库语法时明确标注“请按数据库当前帮助文档核对”，不得杜撰字段。

输出顺序：数据库名称 → 完整检索式 → 语句解释 → 调整建议。

03候选文献筛选与书目信息核验⌄
适用场景区分相关性判断与真实性核验
我不说把这些文献整理一下
我会说（直接复制）
你是一名系统性文献筛选助手。请仅依据我提供的题录、摘要和可访问原文完成初筛，不补写缺失信息。

纳入标准：【填写】
排除标准：【填写】
候选记录：【按编号粘贴】

对每条记录输出：
1. 初筛结论：纳入 / 排除 / 待定。
2. 依据：逐条对应纳入或排除标准，并引用题录、摘要或原文中的可定位信息。
3. 书目信息：标题、作者、年份、期刊、卷期页、DOI或其他永久标识。
4. 核验状态：已由原文/出版社页面确认，或“仅候选信息，尚未核验”。
5. 重复记录、同一研究的不同版本及可能的撤稿/更正风险。

严禁根据标题猜测研究内容；严禁补造DOI。信息缺失时填写“未提供”。最后给出需要人工复核的优先清单。
使用提醒AI可以辅助初筛，但纳排决定和最终书目信息应由研究者在权威来源复核。

04结构化精读单篇论文⌄
适用场景让每项结论都能回到原文
我不说帮我总结这篇论文
我会说（直接复制）
请仅依据我提供的论文全文进行结构化精读，不使用外部知识补充，也不把作者的推测写成研究结论。

论文内容：【粘贴全文或上传文件】
我的研究关注点：【填写】

请提取：研究背景、核心问题、理论框架、研究对象与样本、数据来源、变量或材料、研究设计、分析方法、主要结果、作者主张、贡献、局限和未来研究方向。

证据要求：
1. 每项内容标注章节、页码、表图编号或可定位原句。
2. 区分“作者明确报告”“可由数据直接支持”“你的解释”三种层级。
3. 原文未说明的内容统一写“原文未报告”。
4. 发现摘要、正文、表格或结论不一致时单独列出。

最后用四句话分别概括：研究问题、方法、核心发现、主要贡献。
使用提醒把PDF页码与文内印刷页码区分开，引用位置要能被他人复查。

05审计研究方法与可重复性⌄
适用场景按设计、测量、分析链条逐项检查
我不说看看这篇论文的方法有没有问题
我会说（直接复制）
你是一名严格但克制的方法学审阅者。请仅依据论文原文评估研究方法，不推测作者未报告的步骤。

论文方法与结果部分：【粘贴内容】
研究类型：【实验/观察/调查/质性/计算/其他】

请逐项检查：研究设计与问题是否匹配；样本来源、纳排标准和样本量依据；变量定义与测量效度；对照、随机化、盲法或混杂控制；缺失值和异常值处理；统计或质性分析流程；多重比较、稳健性与敏感性分析；代码、数据和材料可获得性。

每项输出：原文位置、已报告做法、潜在风险、风险为何影响结论、需要作者补充的信息、可执行改进建议。使用“充分 / 部分充分 / 信息不足 / 不适用”评级。

不得仅因未报告就断言作者没有实施；应写“原文未报告，无法判断”。
使用提醒方法审计的重点是证据充分性，而不是替作者猜测实验过程。

06建立主张—证据对应表⌄
适用场景检查每个重要主张由什么证据支撑
我不说告诉我这篇论文讲了什么
我会说（直接复制）
请为以下论文建立“主张—证据—边界”映射。

论文内容：【粘贴内容】

识别正文中最重要的8-15条主张，并对每条输出：
1. 主张原文及位置。
2. 支撑它的数据、分析、图表或引用文献。
3. 证据类型：描述性、相关性、因果性、机制性、理论性或推测性。
4. 支撑强度：直接 / 间接 / 不足，并解释理由。
5. 合理结论边界：适用对象、情境、时间和测量范围。
6. 是否存在过度概括、因果语言过强、结果与讨论不一致或未呈现反例。

不要把统计显著等同于实际重要，不要把相关关系改写成因果关系。最后列出最需要人工复核的3条主张。
使用提醒这条提示词适合写文献笔记、审稿准备和讨论部分的证据校准。

07建立可溯源的文献对照矩阵⌄
适用场景固定比较维度，避免混淆样本和结论
我不说帮我比较这些文献
我会说（直接复制）
请仅依据以下编号文献建立对照矩阵，不使用外部知识补充。

文献：【按P1、P2、P3……编号粘贴】
研究主题：【填写】

比较维度：研究问题、理论框架、研究对象与样本、国家或情境、数据来源、研究设计、变量或编码框架、分析方法、主要结果、效应方向、贡献、局限和证据质量。

要求：
1. 每个单元格标注文献编号和原文位置。
2. 缺失信息填写“未报告”，不得从其他论文移入。
3. 术语不同但概念可能相同时，保留原词并单列“概念对应说明”。
4. 最后总结一致结论、主要分歧、不可直接比较之处，以及差异可能来自样本、情境、测量或方法的哪些方面。

任何因果解释必须说明证据条件；无法判断时写“证据不足”。
使用提醒先做矩阵再写综述，可显著减少不同研究信息串线。

08分析研究结论为何冲突⌄
适用场景系统排查异质性来源，而不是强行统一
我不说这些论文结论不一样，解释一下
我会说（直接复制）
请分析以下文献之间的结论差异，仅使用我提供的内容。

文献矩阵：【粘贴矩阵】
需要解释的冲突：【填写】

请依次检查：研究问题是否相同；概念和变量定义是否等价；样本与情境是否不同；数据时间范围；测量工具；研究设计；模型设定；控制变量；统计功效；结果报告方式；偏倚与局限。

对每个可能来源输出：支持文献及位置、它如何改变结果、当前证据强度、可检验的后续分析或研究设计。区分“有原文证据的解释”和“待验证假设”。

不要为了形成统一结论而忽略不一致；若文献不可比，请明确说明不可比的具体原因。
使用提醒冲突本身可能就是重要发现，但必须先排除定义、样本和方法不一致。

09生成有证据链的文献综述段落⌄
适用场景按观点组织，而不是逐篇罗列
我不说把这些文献写成综述
我会说（直接复制）
你是一名学术综述编辑。请根据以下已核验的文献矩阵撰写【主题】的综述段落。

文献矩阵：【粘贴内容】
目标章节：【引言/相关工作/理论背景/讨论】
引用格式：【作者-年份/编号制】

写作要求：
1. 先提出本段中心判断，再按一致证据、补充证据、反向证据和边界条件组织。
2. 每个实质性判断后标注文献编号，不得添加矩阵中不存在的文献或事实。
3. 明确区分共识、争议、证据不足和情境依赖。
4. 不使用“已有大量研究”等无法量化的套话。
5. 输出正文后附“句子—支持文献—矩阵字段”核对表。

若证据不足以支持某个总结，应删除或降级措辞，而不是补写。
使用提醒综述不是摘要拼接；每段应围绕一个可验证判断组织证据。

10识别有证据支持的研究空白⌄
适用场景区分真正未解决的问题和单纯研究较少
我不说帮我找一个研究空白
我会说（直接复制）
请基于以下文献矩阵识别有证据支持的研究空白，不引入矩阵之外的事实。

文献矩阵：【粘贴内容】
我的资源与研究范围：【填写】

分别检查：理论解释不足、研究对象缺失、情境边界未知、变量机制未检验、测量或方法局限、纵向证据不足、结论冲突和实践问题未解决。

每个候选空白需给出：支持文献及位置、已知与未知的边界、为什么重要、它是否只是“研究数量少”、可验证的研究问题、最低数据需求、可能的反证、预期贡献和主要风险。

采用“证据充分 / 有一定依据 / 证据不足”评级。证据不足的候选项不得包装成确定空白。
使用提醒研究空白需要“已知—未知—为什么重要”的完整证据链。

11把空白转化为研究问题与假设⌄
适用场景让每个假设具有理论机制和可证伪性
我不说根据这个空白写几个假设
我会说（直接复制）
请把以下研究空白转化为可检验的研究问题和假设。

研究空白及证据：【粘贴】
理论框架：【填写】
研究对象与情境：【填写】
可获得数据：【填写】

输出：
1. 一个总研究问题和2-4个子问题。
